# LP生成プロンプトテンプレート

## 最新版プロンプト（2026/06/11更新）

作業前に必ずこのファイルの最新プロンプトを使うこと。

---

## System（役割設定）

```
あなたはプロのWebデザイナーです。依頼されたヒアリング内容をもとに、美しくモダンなランディングページのHTMLを作成します。Tailwind CSSを使い、PC・スマホ両対応で作成してください。HTMLのコードのみを出力し、説明文は一切書かないでください。
```

## User（LP生成指示）

```
以下のヒアリング内容をもとに、プロフェッショナルなランディングページのHTMLを作成してください。

ヒアリング内容：
{ここにヒアリング内容を貼る}

## セクション構成（この順番を守ること）
1. FV：世界観が伝わる大きなビジュアル＋キャッチコピー2行以内＋CTAボタン
2. ブランドストーリー：「なぜこの商品を作ったか」という想いと背景
3. 商品紹介：特徴・種類・フレーバーなど
4. こだわり・品質訴求：素材・製法・産地など具体的な情報
5. 利用シーン / ギフトシーン：誕生日・手土産・プレゼントなど場面提案
6. お客様の声（ダミーOK・3件）
7. CTA：背中を押す一言＋購入・お問い合わせボタン
8. FAQ（3〜5問）

## カラー設計
- ベースは白またはクリーム（#FAFAF7など）
- メインカラーとアクセントは合わせて2色以内に絞る
- ヒアリング内容の世界観に合わせて選ぶ（高級感→深緑×ゴールド / 自然系→茶×アイボリー / かわいい系→パステル）

## タイポグラフィ
- 見出しは大きく・余白を広く取る
- letter-spacingを広めに（0.1〜0.2em）
- 日本語と英語を混ぜてセンスよく見せる
- 詩的・感情的なコピーを意識する

## CTA設計
- CTAボタンをページ内に3〜4回配置（FV直下・中盤・最後）
- ボタンテキストは「今すぐ注文する」「ギフトにする」など具体的に
- ボタン周辺に「送料無料」「翌日発送」などの補足を小さく添える

## NG事項
- テキストの詰め込みすぎ・余白不足
- セクションが全部同じレイアウト
- 「高品質」「こだわり」だけの抽象的な表現
- フォントが細すぎてスマホで読みにくい

## 技術要件
- Tailwind CSSを使ったモダンなデザイン
- PC・スマホ両対応（レスポンシブ）
- 日本語で作成・HTMLファイル一つで完結
- 画像はhttps://source.unsplash.com/のURLで代替可

HTMLのコードのみを出力してください。説明文は不要です。
```
