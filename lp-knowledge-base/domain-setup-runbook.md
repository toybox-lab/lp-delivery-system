# 独自ドメイン納品 手順書（ToyBox LP制作ラボ）

独自ドメイン（例：`toybubble.com`）でLPを納品するための手順。
基本納品は確認用URL（無料・維持費0円）。この手順は「独自ドメイン設定 +3,000円」を選んだお客様のみ。

**ドメイン方針（2026/06/17確定）**：
- 新規ドメインの取得代行は**行わない**（ToyBoxはドメインを購入・保有しない。継続課金もしない）
- 対象は**お客様が既に所有しているドメイン**のみ。お客様が自分のアカウントで取得・所有・更新する
- ToyBoxの+3,000円は「専用リポジトリ作成＋DNS案内＋紐付け＋SSL確認」の**作業代**

---

## 役割分担

| 工程 | 担当 | 備考 |
|------|------|------|
| ① ドメイン取得・所有 | **お客様** | お客様自身のアカウントで取得・更新。ToyBoxは購入しない |
| ② 専用リポジトリ作成＋LP配置 | レオン（スクリプト） | コマンド1発 |
| ③ DNS設定 | **お客様**（値はアンシー下書き＋レオンが提示） | お客様のドメイン管理画面で入力。ログイン情報はもらわない |
| ④ GitHub Pages独自ドメイン有効化＋SSL | レオン | 自動 |

---

## 推奨レジストラ：Cloudflare

理由：
- ドメイン代金が原価（中間マージンなし・.comで年間約1,500円）
- DNS管理画面がシンプル・SSLも安定
- 将来APIで自動化しやすい

※お名前.com等でも可。その場合DNS設定画面の場所が違うだけで、入力する値は同じ。

---

## 手順

### ① お客様：ドメインを取得・所有（ToyBoxは関与しない）
- お客様がヒアリングで `domainName` に記入したドメインは、**お客様自身が所有**している前提
- まだ持っていないお客様には「ご自身でドメインを取得（お名前.com / Cloudflare等）いただければ設定します」と案内する
- ⚠️ ドメインの年額更新料は**お客様負担**（お客様の資産）。ToyBoxは購入も保有も更新もしない

### ② レオン：専用リポジトリ作成＋LP配置
`deploy-custom-domain.sh` を使う（同フォルダ）。
```
bash deploy-custom-domain.sh <repo名> <ドメイン名> <LPファイル名>
例：bash deploy-custom-domain.sh toybubble toybubble.com lp_20260617_toybubble_v2.html
```
このスクリプトが自動でやること：
- `toybox-lab/<repo名>` リポジトリを作成
- LPを `index.html` として配置
- `CNAME` ファイル（中身＝ドメイン名）を配置 → GitHub Pagesが独自ドメインを認識
- GitHub Pagesを有効化

### ③ mizuk：DNS設定（レオンが下記の値を提示する）
レジストラのDNS管理画面で以下を登録：

**Aレコード（4つとも登録）：** ホスト名 `@` → 値：
```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```
**CNAMEレコード：** ホスト名 `www` → 値：`toybox-lab.github.io`

（GitHub PagesのIPは固定。変わったらこの手順書を更新する）

### ④ レオン：独自ドメイン有効化＋SSL確認
- GitHub Pages設定で独自ドメインを有効化（スクリプトで設定済み）
- DNS反映後（数分〜最大数時間）、`https://{ドメイン名}` でアクセスできるか確認
- 「Enforce HTTPS」が有効になっていることを確認（GitHubが自動でSSL証明書を発行）

---

## 納品
- `https://{お客様のドメイン}` でLPが表示される
- Gmail下書きで納品連絡（案件番号・独自ドメインURL・修正フォームURL）

---

## 注意点
- DNS反映には時間差がある（即時〜数時間）。「すぐ見られない」とお客様に言われても焦らない
- 独自ドメイン希望のお客様ごとに専用リポジトリが増える（命名規則：`client-{案件番号下3桁}` 等で管理）
- 更新料（2年目以降）の扱いは事業判断。ヒアリング時に「初年度のみ」と明示しておくと安全
