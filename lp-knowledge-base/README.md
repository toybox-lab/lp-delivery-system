# LP制作 共有知識ベース

すべてのエージェントはLP制作作業を始める前にこのフォルダを確認すること。

## フォルダ構成

- `correction-patterns.md` — お客様からよくある修正パターンと対応例
- `quality-guidelines.md` — LP品質基準・デザインの判断軸
- `prompt-templates.md` — LP生成プロンプトの最新版
- `case-studies/` — 実際の案件ごとの修正履歴

## 使い方

1. 作業前に `quality-guidelines.md` と `correction-patterns.md` を読む
2. LP生成時は `prompt-templates.md` の最新プロンプトを使う
3. 修正が入ったら `correction-patterns.md` と `case-studies/` に記録する
